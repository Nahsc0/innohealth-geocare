# Integrations and source requirements

## NIPOST NDAPS

Reviewed 19 November 2026. The [official postcode site](https://postcode.gov.ng/) links to [organisation registration](https://dashboard.postcode.gov.ng/register). The [Built on Nigeria's Postcode programme](https://pitch.postcode.gov.ng/) describes free development access. NIPOST provides [technical documentation](https://docs.postcode.gov.ng/), a [service reference](https://docs.postcode.gov.ng/concepts/lookup-levels) and an [integration team](https://postcode.gov.ng/integration).

- Register the organisation, then open Settings → API Keys and create a server-side test key with lookup scope. Store it as `NIPOST_API_KEY` in the FastAPI secret store. `nipost_test_` and `nipost_live_` are separate environments. Live access requires verified KYB. GeoCare calls `GET https://api.postcode.gov.ng/v1/lookup?code=…&level=1` with `X-API-Key` and reads the documented boolean `data.valid`. Test with the published sandbox code `FC-01-A01-KP-27`. No credential-backed request was executed during implementation. [Authentication](https://docs.postcode.gov.ng/authentication)
- Validator consumes no credits per the Authentication and Lookup Levels pages. Autofill requires a grant and consumes credits in live mode. The Quickstart's generic credit wording differs, so confirm current billing and exact limits with NIPOST before launch. Per-key rate limits are returned through `X-RateLimit-Limit` and `X-RateLimit-Remaining`; a breach returns 429. The published value 600 is an example. GeoCare reports upstream failures as unavailable and offers alternate location inputs. [Lookup levels](https://docs.postcode.gov.ng/concepts/lookup-levels)
- The published Validator response contains validity; the published Autofill sample contains administrative and house address fields but no coordinates. Nearby search is documented as a capability. Reverse geocoding is separately priced and excluded from the public API reference. Obtain approved coordinate and reverse-geocoding contracts before implementing them. GPS, map selection and manual coordinates serve as the available location inputs. [Authentication](https://docs.postcode.gov.ng/authentication) [Lookup levels](https://docs.postcode.gov.ng/concepts/lookup-levels)
- The widget documentation lists Flutter, Android and iOS SDKs as published, and web and React Native packages pending publication. The widget uses a user identifier. GeoCare's server-side validation does not collect NIN or send an identifier. [NIPOST Widget](https://docs.postcode.gov.ng/widget/overview)
- In local mode without a key, GeoCare uses the single artificial `ZZ` fixture and labels all results as local mock. Set `POSTCODE_MODE=mock` for the same isolated trial on staging. Leave it disabled for staging that should test provider availability only. Review licence terms and applicable restrictions before commercial use or storage of postcode-derived data. [Terms](https://postcode.gov.ng/terms) [Acceptable Use Policy](https://www.postcode.gov.ng/acceptable-use)

## Facility and GIS sources

- The [Nigeria Health Facility Registry](https://hfr.fmohconnect.gov.ng/) provides a read-only [REST and FHIR API](https://hfr.fmohconnect.gov.ng/developers). An authorised operator can request a key there. Its documented REST base is `https://backend.hfr.fmohconnect.gov.ng/api/v1`, with `X-API-Key` and `GET /facilities`. Obtain an authorised extract or approved API access, reconcile records with the Kaduna Ministry of Health and NPHCDA, then enter verified fields through the Admin UI or the authenticated facility API. There is no automated NHFR ingestion or bundled directory data. Preserve facility IDs and source links. Check service availability, hours and contacts independently before publishing these fields.
- Obtain authorised community centroids and population data from the pilot GIS partners. The accessibility tool uses public settlement centroids. Use a vetted, representative dataset and a documented study geography before interpreting the results.
- MapLibre loads raster tiles on demand. Set `NEXT_PUBLIC_TILE_URL` before building the frontend. The public OpenStreetMap tile service is a local development fallback only. Hosted deployments need an approved tile provider or a self-hosted tile service with OSM attribution. [OSM tile policy](https://operations.osmfoundation.org/policies/tiles/)
- Set `OSRM_BASE_URL` to an approved or self-hosted instance with current OSM driving data for Nigeria. The backend uses the Route API and reports only a returned road distance and duration. Plan and disclose coordinate processing and hosting location before enabling routing. [OSRM Route API](https://project-osrm.org/docs/v26.6.1/http)
- Kaduna emergency guidance uses 112, allocated nationally and listed by NCC for Kaduna. [NCC numbering plan](https://ncc.gov.ng/media/836/view) [NCC Kaduna centre announcement](https://ncc.gov.ng/media-centre/press-releases/nccs-kaduna-emergency-communication-centre-five-other-it-projects)
- The supplied corporate site could not be loaded during research. The application uses a GeoCare-specific green and red design and the organisation name provided in the brief. Confirm official brand assets and have a Hausa reviewer check the public copy before a public release.
